# What the free version gives you

Ask your coding agent a question and it runs the CLI against your own database. HTML snapshots show the chronology, evidence gaps and review work. Documents use brand.json. Neither has action buttons or a server.

A screen adds a document viewer, point-and-click highlighting, live collaboration, drag-and-drop timelines and a mobile interface. This version has none of those, and local files do not provide offline synchronisation. It does not transcribe media or extract facts from documents. Enterprise DNA can build the agreed interfaces and connections into your version.

The free version is useful for a trusted casework operator who wants control over a structured fact register and its reports. Source evidence lives separately. It is not a replacement for a discovery review platform, hearing presentation system or legal judgment.
